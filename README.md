# Catch The Turtle

Python ve Turtle Graphics kullanılarak geliştirilmiş basit bir tıklama oyunudur.

## Oyun Hakkında

Oyuncunun amacı, ekranda rastgele hareket eden kaplumbağaya süre dolmadan mümkün olduğunca fazla tıklamaktır. Oyun sırasında skor tutulur, süre geri sayar ve farklı zorluk seviyeleri uygulanabilir.

## Özellikler

* Kaplumbağaya tıklayarak puan kazanma
* Süre sayacı
* Skor takibi
* Zorluk seviyesi sistemi
* Oyun sonu ekranı
* Ses efektleri ve arka plan müziği

## Kullanılan Teknolojiler

* Python
* Turtle Graphics
* Standard Python Libraries

## Öğrenilen Konular

* Modüler programlama
* Olay tabanlı programlama
* Zamanlayıcı kullanımı
* Skor yönetimi
* Dosya organizasyonu
* Basit oyun geliştirme
